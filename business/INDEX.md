# Business - второй мозг бизнеса

Карта папки. Заполняется, когда продукт становится живым (продукт, аудитория, экономика,
маркетинг, цели). Читай только нужный файл, не загружай всё сразу.

| Папка | О чём |
|---|---|
| `products/` | что продаём, тарифы, цены |
| `audience/` | аватары, сегменты, боли, путь клиента |
| `economics/` | выручка, расходы, юнит-экономика |
| `marketing/` | каналы, воронка, конкуренты, контент |
| `goals/` | годовые, квартальные, месячные цели, метрики |
| `assets/` | бренд, лого, отзывы, копи-банк |
| `life-metrics.md` | как взять свежие цифры (маркер **LIVE**), а не хардкодить |
| `raw/` | исходники: транскрипции, переписки |

Связывай логически связанные файлы викилинками `[[имя-файла]]` - в этом `INDEX.md` ссылки на
ключевые файлы, между собой (например `audience/avatar` <-> `audience/objections`). Граф знаний.
