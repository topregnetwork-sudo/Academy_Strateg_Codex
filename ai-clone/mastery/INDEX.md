# Mastery - методологии великих

Личный совет директоров: концентрат методов лучших умов по нужным областям.
Не книги и не пересказы - только методы с пошаговым «как применить».

- Одна папка = одна область (copywriting, negotiations, finance...).
- Один файл = один автор.
- У каждого автора 1-3 гениальных метода: суть / шаги / когда применять.

Список областей появится по мере наполнения.
