# feedback/ - правила, выученные через ошибки

Главная папка клона. Заполняется сама: когда владелец говорит «не так, потому что...» -
Claude оформляет правило сюда, а не запоминает в текущий чат.

Формат файла (`имя-правила.md`):

```
---
name: краткое-имя
description: когда применять
type: feedback
---

Правило одним предложением.

**Почему:** контекст появления, какая ошибка была.

**Как применить:** в каких ситуациях правило срабатывает.
```

Связывай родственные правила ссылками `[[имя-другого-правила]]`.
