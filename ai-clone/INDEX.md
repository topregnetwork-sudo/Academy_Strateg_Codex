# AI-Clone - цифровая проекция владельца

Точка входа. Это НЕ заполненный клон - пустой скелет. Каждый владелец наполняет его под
себя (лучший способ - голосовое интервью с Claude по блокам identity/voice/thinking/
principles). До наполнения клон читать нечего.

## Карта (читай только нужный файл, не загружай всё сразу)
| Файл | О чём |
|---|---|
| `role.md` | Кто владелец: бэкграунд, что важно знать |
| `identity/` | values, vision, mission, biography |
| `voice/` | tone, vocabulary, stop-words |
| `thinking/` | mental-models (как принимаются решения) |
| `principles/` | product, code, business |
| `feedback/` | правила, выученные через ошибки (главная папка, заполняется сама) |
| `style/` | эстетика, что отвергается |
| `reference/` | инструменты, инфраструктура (без секретов) |
| `mastery/` | методологии великих (1 автор = 1 файл, только методы) |

Связывай ключевые файлы викилинками `[[имя]]` (граф знаний): в этом `INDEX.md` - ссылки на
разделы, между родственными файлами - взаимные линки.

> Если у тебя уже есть общий ai-clone на другом проекте - можешь не заполнять этот, а
> указать путь к общему в CLAUDE.md. Тогда одна личность работает во всех проектах.
