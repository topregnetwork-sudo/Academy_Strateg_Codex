# Протокол синхронизации памяти

## Роли хранилищ

- Локальная папка — рабочая копия и место выполнения проверки.
- GitHub — версия безопасных документов, структуры, архитектуры, планов и ретроспектив.
- Google Drive — общая человеческая память и резервная копия служебных документов.

## Правило

Значимый отчёт и стабильное решение сначала проверяются локально, затем при отдельном разрешении дублируются в Drive и публикуются в GitHub. Секреты, PII, credentials, рабочие экспорты и live-конфигурации не синхронизируются.

## Текущий baseline

В Drive уже проверены копии `BATMAN_FUNNEL_MASTER.md`, `OWNER_FUNNEL_MASTER.md` и `KARKASNIK_WORK_PROTOCOL.md`. Без нового разрешения дополнительные записи Drive не выполняются.

## Контроль

Перед публикацией: diff → secret scan → проверка путей → commit/PR → readback. Один следующий шаг для расширения Drive-синхронизации — отдельное разрешение владельца на список файлов.
