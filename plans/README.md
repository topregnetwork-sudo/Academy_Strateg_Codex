# plans/ - технические планы

- Один план = одна фича. Если план есть - работаем с ним.
- Имя файла: `ГГГГ-ММ-ДД-название-фичи.md` (актуальная дата).
- Делится на фазы. Каждая фаза - статус `[ ]` / `[WIP]` / `[x]`.
- В конце плана - итог: реализовано целиком или нет, что осталось.
- Любой агент актуализирует план после каждой сессии.
- Большая фича (больше часа работы) - сначала план. Микрофича - без плана.
