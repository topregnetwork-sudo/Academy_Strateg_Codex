# .claude/ - настройки Claude Code для проекта

- `settings.json` - права и запреты. В `permissions.deny` заложен защитный минимум:
  запрет `rm -rf`, `git push --force`, `git reset --hard` и чтения `.env`
  (паттерн узкий - безобидный `.env.example` читать можно).

Сетевые команды (`curl`/`wget`) намеренно НЕ запрещены: они нужны в обычной работе
(проверить свой же API, скачать файл), а от реальной угрозы - отправки секретов наружу -
блокировка по имени команды всё равно не спасает. Это правило живёт в `CLAUDE.md`
как договорённость, а не как запрет напоказ.

Синтаксис `permissions` в разных версиях Claude Code слегка отличается. Если при старте
Claude ругается на формат - попроси его «обнови знание о Claude Code и приведи
permissions.deny к актуальному синтаксису, сохранив тот же смысл запретов».

Опциональные усиления (по желанию, НЕ включены дефолтом - зависят от ОС и версии):
- звуковой hook на завершение задачи и на запрос разрешения;
- блокирующий pre-tool-use hook, физически запрещающий чтение `.env`.
Попроси Claude настроить их под свою ОС, когда захочешь.
