# База данных

Подтверждённые хранилища: Google Sheets для операционных реестров, сайт для бизнес-теста и результатов, n8n для оркестрации, GitHub/Drive для безопасной памяти.

Точная схема таблиц и полей не дублируется здесь без сверки с live-документом. `schema.prisma` остаётся концептуальным stub и не является разрешением на миграцию базы.
