# Внешние сервисы

## Черновик

*Чужие сервисы по категориям (оплата, почта, хранилище, аналитика, модели). По каждой 2-3 варианта, сравнение, выбор + порт-адаптер (сменная прослойка) + поведение при недоступности + дневной денежный потолок. Общий потолок - в файле 07. Плюс набор полезных MCP.*

## Журнал решений

*Одной строкой на каждое решение: что выбрал и почему (из какой части замысла выросло).*
