# Внешние сервисы

n8n оркестрирует workflow; Telegram доставляет сообщения; Google Sheets хранит операционные реестры; Zoom предоставляет встречи; сайт принимает события `business_test.registered` и `business_test.completed`; Drive и GitHub хранят служебную память.

Кredentials и секреты находятся вне репозитория в `C:\Users\admin\.secrets\`.
