# Архитектура (architecture/)

Договорённость между владельцем и Claude по этому проекту. Чертёж, по которому пишется
код. Собран 2026-08-05. Один файл = один раздел = один промт. У каждого файла в конце -
раздел «Журнал решений» (одной строкой: что выбрал и почему).

## Оглавление
- `00-правила-проекта.md` - 5-7 жёстких проверяемых правил проекта (три группы).
- `01-что-строим.md` - продукт простыми словами + границы первой версии («что НЕ войдёт»).
- `02-сущности.md` - главные вещи продукта и связи между ними (общий словарь).
- `03-база-данных.md` - таблицы, поля, связи, инварианты + `schema.prisma`.
- `schema.prisma` - готовая схема базы (позже в код).
- `04-потоки-данных.md` - что человек видит сразу, что уходит в фон (очереди, идемпотентность).
- `05-стек.md` - выбор технологий («проверенное и скучное») с обоснованием.
- `06-внешние-сервисы.md` - чужие сервисы через порт-адаптеры + потолки трат + MCP.
- `07-безопасность.md` - ПДн, опасная тройка, потолок расходов, роли и права.
- `08-структура-кода.md` - раскладка кода по модулям, карта владения.
- `09-риски.md` - премортем (смертельные / серьёзные / мелкие).
- `10-план-реализации.md` - план работ по неделям + промт на старт кода.
