# Правила архитектуры

- Канонические знания берутся из решений владельца и `02_STABLE_DATA`, а не из шаблонов.
- Всегда одна активная задача; перед изменением — preflight и backup.
- Две воронки: Batman и Owner. Модель четырёх продуктов отозвана.
- Документальная работа не меняет production, credentials, webhook URL, листы и колонки.
- Новые Zoom-ссылки берутся из `Слоты_Zoom` по `выбранный_слот`; отсутствие совпадения — ошибка, а не fallback на старую ссылку.
