# Безопасность

- Секреты, PII и credentials не коммитятся.
- Live-патч допускается только по отдельному подтверждению, с backup и проверкой.
- Нельзя менять названия листов/колонок, webhook URL и рабочие credentials.
- Исторические ссылки не мигрируются массово.
- Zoom-клик не считается фактом прихода.
- Отозванная модель четырёх продуктов не используется как активная память.
